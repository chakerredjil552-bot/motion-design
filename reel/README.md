# Claude Code — self-ad Reel

A 39.2 s (16 bars), 1080×1920, 120 fps Instagram Reel where every frame is generated by code: a canvas renderer inside
Remotion, Python/librosa for the music analysis and mix, FFmpeg for encoding and QA. The edit is cut to the
supplied slowed-phonk track.

## Re-render

```bash
cd reel
./render.sh            # audio -> 3 s test slice -> chunked master -> Reels/30 fps -> cover -> QA
```

Stages can be run on their own: `./render.sh audio | test | master | deliver | cover | qa`.
`master` resumes: chunks that already have the right frame count are kept (`FORCE=1` re-renders them).
If a chunk crashes or runs out of memory it is retried at half the concurrency, down to 1; the script stops with
an error instead of skipping anything. `CONCURRENCY` (default 4) and `CHUNK` (default 588 frames) are env vars.

Requirements (checked by the script): Node 22 + `npm ci`, FFmpeg 6, Python 3 with `audio/requirements.txt`,
and a headless Chromium (defaults to the preinstalled `/opt/pw-browsers/...` build; override with
`REMOTION_BROWSER`). Nothing is fetched at render time: fonts, logo and data are local.

Inputs that are not in git:
- `assets/music/track.m4a` — the song (copy your file there).

## Outputs (`out/`)

| file | what |

## Music → timeline

- **98 BPM** (least-squares fit on 93 kicks: 97.998 BPM, ~9–11 ms residual). Kicks land on every quarter at 98 BPM
  plus syncopated 16ths; the 65 BPM "triplet" reading and 196 BPM double-time were rejected
  (`audio/work/analysis.json` has the numbers).
- **Drop**: song beat 17 = 10.425 s, after a 3-bar build with a natural one-beat dropout.
- The grid is aligned to the audible attacks: the fit locks onto the kick body, but every beat's transient starts
  16.3 ms earlier (median over 16 kick beats), so beats sit 2 ms after the attack onset. Hits land on the
  transient, and the hard cut stops the music 1 ms before the next downbeat's click.
- Excerpt: song 3.064 → 30.003 s. 1 beat = 73.469 frames; every event is rounded to the nearest frame.
- Bullet-time plays the song at ~0.5× (tape varispeed, pitched down an octave, darker) for 4 beats and snaps back
  at frame 3233 without skipping; the hard cut lands right before the next downbeat (frame 3380), at the end of the
  song's own phrase.
- `src/data/beats.json` (kick/snare/cowbell/hat/impact/slam events in master frames) and `src/data/envelope.json`
  (per-frame full/low/mid/high amplitude) drive every audio-reactive visual.

Key frames: drop 882 · skill changes 1029 1322 1616 1910 2204 2351 2645 · contact 2939 · snap 3233 ·
second lunge 3306 · hard cut 3380 · closing 3527 · punchline 3967 · loop back to frame 0 at 4703.

## Code map

- `audio/analyze.py` — tempo/bars/drop/onsets; `audio/build.py` — timeline, re-timed excerpt, synthesized SFX,
  mix, loudness (−14 LUFS, true peak ≤ −1 dBTP), beats.json, envelope.json.
- `src/render.ts` — per-frame pipeline: scene by integer frame, 2–4 motion-blur sub-frames, post stack, HUD.
- `src/lib/` — `core.ts` timing/easing/seeded noise/hit system, `post.ts` bloom/CA/glitch/grain/leaks,
  `figure.ts` rim-lit skeleton silhouettes, `glyphs.ts` text as glyph paths (bit-identical frames).
- `src/scenes/` — `terminal`, `shatter` (lit 3D glass), `worlds` + `onetake` (the skill montage: each world's
  end transforms into the next one's start), `eye3d` (3D anime eyeball), `speaker3d` (3D loudspeaker), `bullet`,
  `punch`, `cover`.
- `scripts/qa.py` — automated QA; `scripts/stills.mjs` — render chosen frames to PNG for review.

Every animation is a pure function of the frame number (seeded randomness, no timers). Frames rendered in
different orders and browser sessions are bit-identical (checked).

## Editing copy

All on-screen copy lives in `audio/build.py` → `copy` (it is written to `src/data/timeline.json`), e.g. the end
tag `"100% code. 0% after effects."`. Run `./render.sh audio` after editing, then re-render.

## Logo

`public/logo/claude-code-original.png` is the supplied file, untouched. `public/logo/claude-code.png` is the
same image with its white background keyed to alpha (`scripts/key_logo.py`: alpha only, colours untouched), so
the eye holes read dark on the near-black background. It is only ever scaled with nearest-neighbour.
